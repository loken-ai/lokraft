# Keyboard

`Cmd` replaces `Ctrl` on macOS for the keys of the views.
The keys of the chat input use `Ctrl` on every system.

## Views

| Key | Opens |
|---|---|
| `Ctrl+1` | Chat |
| `Ctrl+2` | Studio |
| `Ctrl+3` | Models |
| `Ctrl+4` | Logs |
| `Ctrl+5` | Terminal |
| `Ctrl+6` | Settings |

The sidebar shows the digit of each view.
The toggle at the top of the sidebar folds it to its icons.
The pointer on an icon names the view.

## Chat

| Key | Effect |
|---|---|
| `Enter` | sends the prompt |
| `Shift+Enter` | breaks the line |
| `Up` on the first line | recalls the previous prompt |
| `Down` on the last line | recalls the next prompt |
| `Ctrl+Up`, `Ctrl+Down` | recalls the previous or the next prompt from anywhere |
| `Esc` | stops the reply in progress |
| `Ctrl+L` | asks to clear the conversation and the attachments |

A recalled prompt is edited from its end.
Editing it leaves the history.

## Terminal

| Key | Effect |
|---|---|
| `Enter` | runs the command |
| `Up`, `Down` | recalls the previous or the next command |

## Studio

| Key | Effect |
|---|---|
| `Ctrl+Enter` | starts the render, as `Generate` does, `Cmd+Enter` on macOS |

## Dialogs

| Key | Effect |
|---|---|
| `Esc` | closes a confirmation without acting |

The confirmations are the clear of the conversation, the delete of a model, the reset of the settings, the clear of the log and the forgetting of earlier results.

## Viewers

| Key or gesture | Picture viewer | Video viewer |
|---|---|---|
| `Esc` | closes | closes |
| `Left`, `Right` | the previous or the next picture of the set | 1 frame back or forward |
| `Space` | | plays or pauses |
| `R` | | resets the zoom |
| Click on the picture | | pauses or plays |
| Wheel or pinch | zooms | zooms |
| Drag | pans | pans |
| Click beside the picture | closes | closes |

`Fit` resets the zoom of a picture or a clip.
